# DDL 용어사전 추출기 (ddl-term-extractor)

PostgreSQL DDL(`CREATE TABLE`, `COMMENT ON`, 인라인 `--` 주석)을 파싱해 DA# 표준용어 사전에 넣기 좋은 형태로 정리하고, SQLite에 누적 저장하며 Excel로 내보낼 수 있는 도구입니다.

## 목적

- 테이블·컬럼 정의와 주석을 한 번에 모아 **용어명·용어영문명·인포타입·데이터타입** 등을 자동으로 채운 시트를 만든다.
- **표준 도메인 사전**(SQLite)에서 도메인명·PG 타입·길이별로 **도메인명 / 인포타입 / 데이터타입** 규칙을 관리하고, 추출 시 접미 도메인과 컬럼 타입이 맞으면 반영한다.
- 여러 번 DDL을 넣어도 **용어영문명(컬럼명) 기준**으로 중복을 제거하고 최신 정보로 갱신한다.
- 수만 건 규모도 SQLite·Excel로 관리 가능한 수준을 전제로 한다.

## 요구 사항

- **Python 3.12 이상** (권장)
- Windows 기준으로 동작을 확인했습니다.

## 설치 방법

프로젝트 루트(`ddl-term-extractor`)에서 다음 중 하나를 사용합니다.

### 방법 A: uv 사용 (권장)

[uv](https://github.com/astral-sh/uv)가 있으면 의존성과 가상환경이 한 번에 맞춰집니다.

```powershell
cd C:\my\ddl-term-extractor
uv sync
```

### 방법 B: pip 사용

```powershell
cd C:\my\ddl-term-extractor
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

또는 `pyproject.toml` 기준:

```powershell
pip install -e .
```

## 실행 방법

### uv로 실행

```powershell
cd C:\my\ddl-term-extractor
uv run streamlit run app.py
```

### 가상환경 활성화 후 실행

```powershell
cd C:\my\ddl-term-extractor
.\.venv\Scripts\Activate.ps1
streamlit run app.py
```

브라우저에서 **http://localhost:8501** 로 접속합니다.

## 데이터 저장 위치

- SQLite DB 파일: **`data/terms.db`** (최초 실행 시 `data` 폴더가 생성됩니다.)
- WAL 모드 사용 시 같은 폴더에 `-wal` / `-shm` 파일이 생길 수 있습니다.

## 기능 목록

| 구분 | 설명 |
|------|------|
| DDL 입력 | 텍스트 영역에 붙여넣기, 또는 `.sql` / `.txt` / `.ddl` 파일 업로드 |
| PostgreSQL 파싱 | `CREATE TABLE`, `COMMENT ON TABLE` / `COMMENT ON COLUMN`, 컬럼 뒤 인라인 `--` 주석 |
| 용어명 | `COMMENT ON COLUMN` 우선, 없으면 인라인 `--` 주석, 괄호 안 보조 설명은 용어명에서 제거 |
| 용어영문명 | 컬럼명 **소문자 snake_case** |
| 용어정의 | 추출 단계에서는 비움 (용어 DB 재추출 시 빈 값은 기존을 덮어쓰지 않음) |
| 도메인명·인포타입·데이터타입 | 표준 도메인 사전에 매칭되면 사전 값 사용, 아니면 인포타입·데이터타입만 DDL 기준 자동 생성·도메인명은 비움 |
| 표준 도메인 사전 | `표준 도메인 사전` 탭에서 편집·저장. 최초 1회 PostgreSQL용 기본 세트 자동 삽입. **기본 세트로 복원**으로 초기화 가능 |
| 추출 결과 미리보기 | 테이블로 표시 |
| 이번 추출 Excel | `용어 추출` 탭에서 **표준용어사전 다운로드 (이번 추출 N건)** — `표준용어사전_이번추출.xlsx` |
| SQLite 누적 | 추출 시 **용어영문명** 기준 UPSERT (신규/갱신 건수 표시) |
| DB 현황 | 사이드바에 누적 건수, 용어명 유·무 통계 |
| 표준용어사전 Excel (누적) | 사이드바 **표준용어사전** — DB 전체 `표준용어사전.xlsx` |
| 표준도메인사전 Excel | 사이드바 **표준도메인사전** — `표준도메인사전.xlsx` (`표준 도메인 사전` 탭과 별도) |
| 누적 데이터 초기화 | 사이드바 **누적 데이터 초기화** 확장: 표준용어사전(`terms`) / 표준도메인사전(`standard_domains`) 각각 동의 체크 후 삭제 (되돌리기 불가) |

## DDL 작성 시 참고

- `COMMENT ON COLUMN`이 있으면 용어명에 가장 우선 반영됩니다.
- 인라인 주석만 있는 컬럼은 그 텍스트가 용어명 후보로 사용됩니다.
- 주석이 전혀 없는 컬럼은 용어명이 비어 있을 수 있습니다.
- 여러 테이블에 같은 컬럼명이 있으면 DB에는 **한 건**으로 합쳐집니다.

## 표준 용어 사전 (누적·Excel)

- **저장 위치**: SQLite `terms` 테이블(`data/terms.db`). 추출할 때마다 같은 **용어영문명**(DDL 컬럼명의 소문자 `snake_case`)이면 **한 행으로 합쳐지며** UPSERT로 갱신됩니다.
- **시트·레코드 컬럼**(순서 고정): **용어명, 용어영문명, 용어정의, 도메인명, 인포타입, 데이터타입** — DA# 표준용어 사전에 맞춘 `HEADER`와 동일합니다.
- **용어정의**: 추출 결과에서는 비워 두고, DB에 이미 적힌 정의가 있으면 **빈 값으로 덮어쓰지 않습니다**. 용어명·도메인명·인포타입·데이터타입은 추출값이 비어 있으면 기존 DB 값을 유지하는 방식으로 병합합니다.
- **Excel 내보내기**
  - **누적 전체**: 사이드바 **표준용어사전 다운로드** (`표준용어사전.xlsx`).
  - **이번 DDL만**: `용어 추출` 탭 추출 후 **표준용어사전 다운로드 (이번 추출 N건)** (`표준용어사전_이번추출.xlsx`).
- **초기화**: 사이드바 **누적 데이터 초기화**에서 **표준용어사전**만 선택해 `terms`를 비울 수 있습니다. 표준도메인사전 삭제는 별도 체크·버튼입니다.

## 표준 도메인 사전 (매칭 규칙)

- 한글 용어명에서 추출한 **접미 도메인명**(예: `일자`, `ID`, `여부`)과 DDL 컬럼의 **PostgreSQL 기준 타입**(`VARCHAR`, `INTEGER`, …)이 같고, 사전 행에 **길이**가 지정돼 있으면 DDL 쪽 길이와 일치할 때만 고릅니다. **길이를 지정한 행**이 지정하지 않은 행보다 우선합니다. (소수 자리는 표준도메인사전에서 관리하지 않으며, DDL에서 파싱한 스케일은 인포타입 자동 생성 등에만 반영됩니다.)
- **데이터타입·인포타입** 칸을 비우면: 데이터타입은 DDL 그대로, 인포타입은 `도메인명 + 타입약어 + 길이` 규칙으로 생성합니다.
- 표준 도메인에 **맞는 행이 없으면** 도메인명은 비우고, 인포타입은 한글 접두 없이 **타입약어+길이만** 씁니다 (예: `VC50`, `INT`, `TS`).

## 프로젝트 구조 (요약)

```
ddl-term-extractor/
  app.py              # Streamlit UI
  core/
    parser.py         # DDL 파싱
    extractor.py      # 용어 레코드 변환
    domain_catalog.py # 표준도메인 매칭
    excel_writer.py   # Excel 출력
    db.py             # SQLite(용어·표준도메인)·초기화
  data/
    terms.db          # 누적 DB (실행 후 생성)
  tests/              # 샘플 SQL 등
```
